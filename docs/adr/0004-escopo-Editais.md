# ADR 0004: Decissão de Ampliar os portais

**Status:** aceito

## Contexto e Decisão

O sistema utilizava somente os editais do [DEG](https://deg.unb.br/) e isso apresentou uma falta de diversidade nos tipos buscados, diminuindo a usuabilidade real da aplicação, o qual o usuario poderia somente utilizar o site oficial. Dessa forma, decidiu-se um aumento no escopo incluindo os seguintes portais.
