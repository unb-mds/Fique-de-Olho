Git e GitHub o que é?

Git:

O Git é um sistema de controle de versão, utilizado para registrar e acompanhar as alterações feitas em arquivos e projetos ao longo do tempo.

Com o Git, é possível:

* Salvar diferentes versões do projeto;
* Voltar para versões anteriores;
* Identificar quem fez cada alteração;
* Trabalhar em equipe sem perder mudanças.

GitHub:

O GitHub é uma plataforma online que hospeda repositórios Git, permitindo:

* Armazenar projetos na nuvem;
* Compartilhar códigos;
* Trabalhar em equipe;
* Fazer revisão de código e controle de alterações.

Relação entre Git e GitHub:

Git= Ferramenta de controle de versões.
GitHub= Plataforma para armazenar e compartilhar projetos Git.

Conceitos Pricipais:

* Repositório: pasta do projeto controlada pelo Git.
* Commit: registro das alterações realizadas.
* Branch: ramificação para desenvolver funcionalidades separadamente.
* Merge: união das alterações de diferentes branches.
* Push: envia alterações para o GitHub.
* Pull: baixa alterações do GitHub.
* Clone: copia um repositório do GitHub para o computador.
